# Inverted Pendulum Simulation

Симуляция системы «Перевернутый маятник на тележке» на языке Python. Проект визуализирует физику движения и работу алгоритмов управления для стабилизации неустойчивого равновесия.

---

## 🚀 Особенности
* Физический движок: Решение дифференциальных уравнений движения с помощью scipy.integrate.
* Алгоритмы управления: Каскадная система PID-регуляторов для стабилизации угла и позиции.
* Визуализация: Реализация графики и анимации на библиотеке Pygame.
* Математическая база: Использование NumPy для работы с векторами состояний и SciPy для расчетов.

---

## 🛠 Установка и запуск

1. Убедитесь, что у вас установлен Python 3.x.
2. Установите зависимости:
   pip install pygame numpy scipy matplotlib
3. Запустите симуляцию:
   python main.py

---

## ⚙️ Как это работает
* Модель: Система описывает движение тележки массой M и маятника массой m длиной l.
* Вектор состояния: Программа отслеживает 4 параметра — [x, dx, theta, dtheta].
* Управление: 
  - Внешний контур (PID_X): рассчитывает нужный наклон маятника для возврата тележки в центр.
  - Внутренний контур (PID_Theta): рассчитывает силу, необходимую для удержания маятника в заданном угле.
